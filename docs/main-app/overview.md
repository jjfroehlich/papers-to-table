# Main app overview

The main app is the primary product surface.

It ingests PDFs plus a structured spreadsheet, proposes evidence-backed values, supports review in a browser UI, and exports audited workbook updates.

Use browser review for normal human operation. Use headless mode for automation only when appropriate.

- Headless workflow: [headless.md](headless.md)
