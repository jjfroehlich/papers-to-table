# Specs and truth model

Use the following distinction:

- **Specs (`specs/`)**: canonical, rebuild-grade product/tool/contracts truth.
- **Docs (`docs/`)**: user/operator/developer manual and workflows.
- **README**: concise repo entry point.
- **Agent skill**: focused operating procedure for headless agent use.

Start with `specs/README.md` (from repository root) for spec reading order.
