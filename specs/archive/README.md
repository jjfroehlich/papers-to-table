# Historical Archive

## Purpose

This directory preserves historical legacy spec files.

Nothing here is the current source of truth. Current behavior lives in `../spec.md`, `../plan.md`, `../tasks.md`, and JSON schemas under `../contracts/schemas/`.

## Structure

- `verbatim/`: preserved legacy major spec files from the pre-unification stacks

## How to use it

- Read the current spec tree first.
- Use `verbatim/` only when you need old wording, historical acceptance language, or deeper superseded rationale.

## Editing rule

Do not turn this directory into a second current spec surface.

If historical material needs to stay, keep it as preserved history rather than adding new migration bookkeeping layers.
